# Paper map — every element to its folder and script

Numbering follows the submitted paper: main Tables 1–2 and Figures 1–2; Appendices A–L with
Tables 3–31 and Figures 3–11. There is no separate supplementary document: details that the
appendix leaves out are listed, with their records, in [APPENDIX_DETAILS.md](APPENDIX_DETAILS.md).

"CPU time" is what *this release* measured. Rows marked **not re-run in this release** were
produced on GPUs during the research and only their stored outputs are shipped; the login node
used to build this release has no GPU.

Experiment folders use the authors' internal IDs (E3 … E22, X1 … X4). Each folder's own
`SUMMARY.md` and `PREREG.md` are authoritative for what it claims.

Figures 3–11 are regenerated by the scripts in [code/figures/appendix/](../code/figures/appendix/)
(`bash code/figures/appendix/run_all.sh`, about 45 s on CPU in total). Each script parses the
numbers it plots from the appendix LaTeX shipped next to it (`paper_tex/`) or from the released
records, recomputes every interval and p-value from counts, and stops if anything disagrees.
